# SLS Website Preview

Eigenstaendiger Preview-Neuaufbau fuer SLS Immobilienpartner GmbH.

## Lokal starten

```bash
npm run preview
```

Danach ist die Preview unter `http://127.0.0.1:4173` erreichbar.

## QA

Die Browser-QA folgt dem Fleisswerker QA Standard v1.0 und prueft alle fuenf Kernrouten auf Desktop, Tablet und Mobile.

```bash
npm run qa
```

Das Kontaktformular ist bewusst als Preview gekennzeichnet und sendet noch keine Daten. Rechtstexte verweisen bis zur Kundenfreigabe auf die bestehende Live-Seite.

Die verwendeten Preview-Bilder sowie die eingebundenen Markenassets sind in `ASSET-NOTES.md` dokumentiert.
